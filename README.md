# 📝 React To-Do List App

A modern, fully functional, and user-friendly To-Do List application built with **React**. This app supports task creation, editing, deletion, due dates, dark/light themes, completion filters, persistent storage, and drag-and-drop reordering (optional).

## 🔧 Features

- ✅ Add, edit, and delete tasks
- ⏎ Press **Enter** to add tasks quickly
- 🕓 Assign a **due date** to tasks
- 🌙 Toggle between **Light and Dark mode**
- 📂 Filter tasks: All | Active | Completed
- ✅ Mark tasks as complete/incomplete
